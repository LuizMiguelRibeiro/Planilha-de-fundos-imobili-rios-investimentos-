# Planilha-de-fundos-imobili-rios-investimentos-
Esta é uma planilha do Excel feita com o propósito de otimizar a sua base de investimentos. Com ela, você pode ajustar o período em anos e a sua renda mensal para que ela sugira um valor de aporte adequado ao seu orçamento, além de contar com diversas outras funcionalidades implementadas.
